# Cachetazo

Duelo a cachetazos en primera persona. Uno crea la sala y le pasa el código de 4 letras a sus amigos; también se puede entrar a una sala solo para mirar.

- El juego es un solo archivo: `index.html`.
- Las salas online usan Firebase Firestore (proyecto `aguara-26448`, el mismo de Aguará), en `salas/cachetazo-<código>/partidos`. Las reglas actuales de ese proyecto ya lo permiten y no se mezcla con las salas de Aguará.
- Modos: práctica, torneo y 3 vs 3 contra la máquina; en sala: duelo, eliminación directa, todos contra todos, 2 vs 2 y 3 vs 3 (con espectadores).
- Personajes: más de 65, entre originales, figuras históricas y personajes clásicos de dominio público. Se consiguen con desafíos, el pase de batalla y los cofres.
- Cada personaje guarda sus accesorios (guantes, gorro, camiseta y coreografía de festejo). Hay seis escenarios.
